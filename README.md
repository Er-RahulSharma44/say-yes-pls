# Say Yes Please! 💕

A fun and interactive Valentine's Day proposal game built with Next.js. Create a customized proposal link and share it with your special someone!

## Features

- 🎨 **Customizable Proposal**: Add your name, custom question, and button text
- 🎭 **Theme Options**: Choose from Love, Friends, Funny, Romantic, or Cute themes
- 🎯 **Interactive Game**: The "No" button moves away when you try to click it (it's impossible to say no!)
- 🎉 **Celebration Animation**: Beautiful confetti and hearts when they say "Yes!"
- 🌟 **Futuristic Design**: Modern, glitchy, neon aesthetic
- 🔗 **Shareable Links**: Generate a unique link to share with anyone

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## How to Use

1. Fill out the form on the homepage with:
   - Your name
   - Your question (e.g., "Will you be my valentine?")
   - Choose a theme
   - Customize button texts

2. Click "Create & Get Link" to generate your unique proposal link

3. Copy and share the link with your special someone

4. When they open the link, they'll see your customized proposal with the moving "No" button!

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- CSS Modules

## Enjoy! 💖

Have fun creating your proposal and good luck! 🍀
