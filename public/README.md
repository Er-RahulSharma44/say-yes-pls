# Public Folder

This folder contains static assets that are served by Next.js.

## Image for "I Knew It" Section

To use your own image for the "I Knew It" celebration:

1. Place your image file in this folder (`/public/`)
2. Name it exactly: `i-knew-it.png` (or `.jpg`, `.webp`, etc.)
3. The app will automatically use it!

**Supported formats:** PNG, JPG, JPEG, WEBP, SVG

**Recommended size:** 600x300px or similar aspect ratio (2:1)

If the image is not found, it will fallback to a placeholder SVG.
